# New Networks

A slow gazette of mobile network codes assigned and withdrawn worldwide, read from the ITU Operational Bulletin and checked against national registries.

Live at https://nickcarbone.github.io/new-networks/

To report an error, open a correction issue in this repo. The page's "Correct this" links fill in the code and holder for you.

`RUNBOOK.md` describes how each issue is produced, and `run.sh` runs the pipeline.
